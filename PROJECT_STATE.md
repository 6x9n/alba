# PROJECT_STATE

## 1. Project Overview
- Project Name: شركة ألبا الحديثة التجارية (Alba Pro)
- Type: Static HTML/CSS/JS website — Hotel equipment catalog
- Target: B2B hospitality buyers in Saudi Arabia
- Core Goal: Showcase products with elegant presentation and WhatsApp inquiry CTA

## 2. Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Cairo font (Google Fonts)
- RTL-first layout (dir="rtl")
- Google Maps embed for location
